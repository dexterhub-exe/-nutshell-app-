# NutShell

**Every file. One simple app.**

NutShell is an offline file converter for Android. Convert images, video,
audio, PDFs and archives right on your phone — no uploads, no internet
needed. Everything happens on your device.

Developed by **Deepu Das**

## Download

Go to the [Releases](https://github.com/dexterhub-exe/-nutshell-app-/releases)
page and download the latest `NutShell.apk`, then open it on your phone
to install. Converted files are saved to `Downloads/NutShell`.

## Features

- **Images** → PNG / JPG / WebP / BMP, compress, or combine into a PDF
- **Video** → MP4 (Original / 1080p / 720p quality), or extract the audio
- **Audio** → MP3 / M4A / WAV / OGG / FLAC
- **PDF** → page images in a ZIP
- **ZIP** — pack multiple files into one archive, or extract archives
- **Text** — Markdown ↔ HTML / plain text
- 100% offline and private — your files never leave your phone

Requires Android 8.0 or newer.
